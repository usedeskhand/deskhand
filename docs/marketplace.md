# Marketplace

Any running agent can be published as a listing: a description, a price in USDG (or free), and a version. A listing shows its rules, the permissions it asks for and its 30-day replay before anyone installs it.

**Installing** gives the buyer their own copy of the rules with their own budget and their own mode. The creator never sees or controls the copy.

**Paid listings** are paid with a plain USDG transfer from the buyer's wallet to the creator's. The server only checks the transfer on chain (sender, recipient, amount) and that the same hash was not used before. Deskhand takes no cut and never holds the money.

**Versions**: a creator publishes new rules as a new version with a note. Existing installs keep the version they installed.

An agent installed from someone else's listing cannot be republished.
